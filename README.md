# adityajain.me

My personal portfolio and blog — built with [Astro](https://astro.build) and deployed to
GitHub Pages at **[adityajain.me](https://adityajain.me)**.

## Development

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # -> dist/
```

See [`CLAUDE.md`](./CLAUDE.md) for architecture, how to add blog posts, and deployment notes.
